# Malha ferroviária

Projeto desenvolvido para a disciplina de Teoria dos Grafos, com o objetivo de aplicar conceitos de grafos na modelagem e análise de uma malha ferroviária real.

O sistema representa estações como vértices e as conexões ferroviárias como arestas, permitindo analisar a conectividade da rede e buscar soluções para problemas relacionados a deslocamento e expansão da malha.

## Objetivos

- Modelar uma malha ferroviária utilizando grafos
- Analisar a conectividade entre as estações
- Identificar pontos importantes da rede
- Encontrar os menores caminhos entre estações
- Analisar possibilidades de expansão da malha ferroviária
